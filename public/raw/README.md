# Drop zone

Put documentation files here using the naming rules in `PROJECTS-INTAKE.md`:

```
p01-logo.png
p01-preview.png
p01-desktop-01.png
p01-mobile-rec.mp4
arc-01.png … arc-10.png
```

Nothing in this folder is served to the site. Files are converted and moved to
their final paths (`public/projects/`, `public/work/`, `public/frames/`,
`public/arc/`) as part of processing.
